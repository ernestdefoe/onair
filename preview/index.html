How it's built (Flarum 2): the LIVE badge overrides the shared Avatar component (main-bundle → safe to extend at init) and reads a serializer-supplied user.isLive(). Presence runs through app.onair.presence, which picks RealtimeTransport when flarum/realtime is detected and falls back to PollingTransport (GET /api/onair/live) otherwise. Pro is a separate proprietary package (ernestdefoe/onair-pro) that requires the free ernestdefoe/onair and plugs the RTMP/HLS pipeline into Lite's provider registry. See ROADMAP.md.
